Instructivo del Sistema

Ventas — Estado del comprobante

Refleja en qué etapa está el comprobante, desde que sale de piso hasta que se cobra:

Pendiente → En piso para hoja de ruta → En tránsito de reparto → En piso para reparto → Entregada conforme → Pagada

Se puede cambiar a mano desde "Editar" en la fila de la venta, o filtrar por estado en la pestaña Ventas.

Cobros

  • El "Haber" de un cobro debería ser siempre igual a Efectivo + Transferencia + Importe Cheque. Reportes y Dashboard usan esta suma (no el Haber directo) para no arrastrar cargas mal hechas.
  • Un cobro puede tener uno o varios cheques — al guardarlo, cada cheque se crea o actualiza automáticamente en Cheques Recibidos, vinculado a ese cobro.
  • La carga masiva (CSV) descarta filas 100% duplicadas dentro del mismo archivo (mismo cliente, fecha, montos y comprobante), y solo reemplaza el último mes con datos del archivo.

Fletes y Gastos — Estado de pago

Pendiente = todavía no se pagó. Pagado = ya se pagó.

Un Gasto no se puede cargar si el proveedor no está dado de alta en la pestaña Proveedores (match por nombre). Si el gasto se paga con Método de Pago = Cheque, hay que elegir de la lista de cheques recibidos disponibles (no vencidos, no entregados) — al guardar, esos cheques pasan a estado Entregado automáticamente.

Cheques Recibidos

  • Vigente / Próximo (≤7d) / Vencido: según la Fecha de Vencimiento (Fecha de Pago + Días de validez).
  • Entregado: el cheque ya salió — se usó para pagar un gasto, o se marcó a mano con el checkbox "Entregado" en el modal. Mientras no esté Entregado y no esté vencido, aparece como disponible para pagar gastos.
  • Si el cheque viene de un Cobro, el Cliente y los datos del cheque se sincronizan desde ahí — no se editan a mano en Cheques Recibidos.
  • Si el cheque se usó para pagar un Gasto, el Entregado/Monto Salida/Fecha Salida se administran desde ese Gasto, no a mano.

Cheques Emitidos

Estado libre (Pendiente / Pagado / Rechazado / Anulado). El Cliente/Proveedor y el Chofer deben estar dados de alta en Clientes o Proveedores respectivamente — si no matchean, no se puede guardar.

Saldos de Clientes — Al día / Pendiente / Deudor

  • Si el cliente no tiene ninguna venta ni pago en el mes actual ni en el anterior → Deudor, sin importar el saldo.
  • Si tuvo movimiento reciente, se mira el mes actual: Ventas del mes − Cobros del mes. Si es ≤ 0 → Al día. Si es > 0 y hubo ventas ese mes → Pendiente.
  • El "Saldo Pendiente" que se muestra en la columna y en las tarjetas es distinto: es la diferencia acumulada de toda la historia (todas las ventas menos todos los pagos), no solo del mes actual.

Carga de datos

  • Ventas y Gastos: la carga masiva reemplaza todos los meses que traiga el archivo.
  • Cobros: la carga masiva reemplaza solo el último mes con datos del archivo (para no pisar meses viejos con un archivo parcial).
  • Clientes: el ID se genera solo (CLIxxxx, correlativo) — nunca se toma del archivo. Al cargar clientes nuevos, se reintenta el match de Ventas y Cobros que habían quedado sin cliente asignado.
  • Rubros y Bancos son maestros editables: se pueden agregar nuevos con el botón "+ Nuevo" en el modal correspondiente, sin salir de la pantalla.
